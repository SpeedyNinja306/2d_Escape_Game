# Escape from Epstein

A 2D top-down stealth game built in JavaFX, inspired by Pokemon-style exploration.

## Concept
You're exploring a small town when an NPC named Jeffrey invites you to his island.
What starts as a simple trip turns into an escape mission through 7 increasingly
difficult dungeon rooms, avoiding guards, finding keys, and making it out alive.

## Built With
- Java
- JavaFX

## Status
🚧 Currently in active development

## How to Run
1. Clone the repo
2. Open in IntelliJ IDEA
3. Run `main.java`
